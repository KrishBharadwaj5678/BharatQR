<h1 align="center">
  <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/icons/icon.png" width="35"/> BharatQR
</h1>

<p align="center">
  BharatQRは、個人や企業が支払い用のUPI QRコードをすぐに作成できる、高速で安全なUPI QRコードジェネレーターです。
</p>

![BharatQRDemo](https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/demos/BharatQRDemo.png)

<img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
|---|---|
| 🔗 UPI QRコードの生成 | UPI IDを入力するだけで生成 |
| 🔓 サインアップ不要 | アカウント作成や登録は不要 |
| ✨ シンプルなインターフェース | 使いやすく、簡単に操作できるデザイン |
| 🚀 QRコードを即時生成 | 素早く支払いを受け付け可能 |
| 📥 QRコードのダウンロード | 生成したQRコードを簡単にダウンロード |

## <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/BharatQR.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd BharatQR
```

### 3️⃣ 必要な依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash
streamlit run app.py
```
