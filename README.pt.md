<h1 align="center">
  <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/icons/icon.png" width="35"/> BharatQR
</h1>

<p align="center">
  BharatQR é um gerador de códigos QR UPI rápido e seguro que permite a pessoas e empresas criarem instantaneamente códigos QR para receber pagamentos.
</p>

## <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
|---|---|
| 🔗 Gerar códigos QR UPI | Basta inserir o seu UPI ID |
| 🔓 Sem necessidade de cadastro | Não é necessário criar uma conta ou se cadastrar |
| ✨ Interface simples | Fácil de usar e navegar |
| 🚀 Geração instantânea de QR | Receba pagamentos de forma rápida |
| 📥 Baixar código QR | Baixe facilmente o código QR gerado |

## <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros passos

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/BharatQR.git
````

### 2️⃣ Acessar o diretório do projeto

```bash
cd BharatQR
```

### 3️⃣ Instalar as dependências necessárias

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar a aplicação

```bash
streamlit run app.py
```
