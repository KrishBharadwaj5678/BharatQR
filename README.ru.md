<h1 align="center">
  <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/icons/icon.png" width="35"/> BharatQR
</h1>

<p align="center">
  BharatQR это быстрый и безопасный генератор UPI QR-кодов, который позволяет частным лицам и компаниям мгновенно создавать QR-коды для приёма платежей.
</p>

## <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|---|---|
| 🔗 Создание UPI QR-кодов | Просто введите свой UPI ID |
| 🔓 Без регистрации | Не требуется создавать аккаунт или регистрироваться |
| ✨ Удобный интерфейс | Простой и понятный интерфейс |
| 🚀 Мгновенное создание QR-кода | Быстрое принятие платежей |
| 📥 Скачивание QR-кода | Легко скачивайте созданный QR-код |

## <img src="https://github.com/KrishBharadwaj5678/BharatQR/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/BharatQR.git
````

### 2️⃣ Переход в директорию проекта

```bash
cd BharatQR
```

### 3️⃣ Установка необходимых зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
